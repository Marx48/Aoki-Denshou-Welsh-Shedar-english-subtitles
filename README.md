**Unofficial fan-made English subtitles for the anime Aoki Denshou; Welsh &amp; Shedar.**
This repository contains English subtitles in Advanced SubStation Alpha (`.ass`) format for the anime **Aoki Denshou Welsh & Shedar** (青き伝承 ヴェルシュ＆シェダル).

## 📄 File Details

* **Format:** `.ass` (Advanced SubStation Alpha)
* **Language:** English
* **Source Language:** Japanese
* **Styles & Timings:** Preserved and synchronized for standard video releases.

## 📥 How to Use

1. Download the `.ass` subtitle file from this repository.
2. Place the `.ass` file in the same directory as your anime video file.
3. Rename the `.ass` file so that it matches the exact filename of the video (e.g., `Episode_01.mp4` and `Episode_01.ass`).
4. Open the video in a media player that supports soft subtitles (e.g., **VLC**, **mpv**, or **MPC-HC**).

Alternatively, you can load the subtitle file directly into video editors or subtitle software such as **Aegisub**.

## ⚙️ Editing & Aegisub

If you wish to modify fonts, styling, or timing, open the `.ass` file using [Aegisub](http://www.aegisub.org/).
